# Code of Conduct

## Our pledge

We pledge to make participation welcoming and harassment-free regardless of age, disability, ethnicity, sex characteristics, gender identity/expression, experience, education, socioeconomic status, nationality, appearance, race, caste, color, religion, or sexual identity/orientation.

## Expected behavior

- Be respectful, specific, and constructive; critique code and ideas, not people.
- Give reproducible feedback and acknowledge uncertainty.
- Respect privacy, credentials, private repository content, and disclosure boundaries.
- Accept responsibility and repair harm.

Harassment, threats, stalking, discrimination, sexualized attention, trolling, insults, sustained disruption, publishing private information, disclosure pressure, and retaliation are unacceptable.

## Scope and enforcement

This code applies in repository issues, pull requests, reviews, discussions, project channels, and when representing the project publicly.

Report concerns privately through the contact method on [the maintainer's GitHub profile](https://github.com/psagar29). Do not publish sensitive personal information. If the concern involves the maintainer or no safe project route exists, use [GitHub Support](https://support.github.com/contact/report-abuse).

Reports will be reviewed promptly, confidentially, and without retaliation. Include dates, links, screenshots, and witnesses when safe. Maintainers may remove contributions and warn, restrict, or ban contributors. Responses should be proportional, privately documented, and focused on safety.
