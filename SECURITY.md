# Security policy

Do not open a public issue for a suspected vulnerability. Contact the repository owner privately through the security reporting channel configured on the GitHub repository.

Never include credentials, private repository content, customer data, or exploit details in reports, logs, fixtures, receipts, or pull requests. Revoke any credential that may have been exposed before reporting it.

Only the latest released version is supported. Antibody is currently pre-release; no production deployment is supported yet.
